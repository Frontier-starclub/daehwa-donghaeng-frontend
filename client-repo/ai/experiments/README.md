# 실험

프롬프트 튜닝, 매핑 실험, 선행연구용 스크립트·노트북을 둔다.

**이 폴더는 배포 이미지에 들어가지 않는다** (`.dockerignore`). 무거운 의존성을 자유롭게
써도 서비스 이미지가 오염되지 않는다. 서비스 런타임 의존성은 `pyproject.toml`에만 넣는다.

## 트랙

| 트랙 | 내용 | 시점 |
| --- | --- | --- |
| (a) 약 이름 → 품목기준코드 매핑 | Blocker B. 정규화 → 부분일치 → 유사도 순서로 시도 | Phase2-A |
| (b) OCR 프롬프트 튜닝 | `evals/ocr/` 평가셋으로 측정하며 조정 | Phase2-A~B |
| (c) 대화 어휘·문장구조 변화 지표 | FT-05 선행연구. MVP 범위 밖 | Phase3 이후 |

(c)는 회의록 안건1 결론("기능구현만 되도록, 분석은 제외")에 따라 MVP에서 제외됐다.
Phase3에 여유가 생기면 착수한다.

## 규칙

- 실험 결과 수치는 커밋한다. 원본 이미지·음성은 커밋하지 않는다.
- 실험에서 검증된 것만 `app/`으로 옮긴다. 실험 코드를 서비스가 import 하지 않는다.
