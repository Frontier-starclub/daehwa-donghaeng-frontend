# OCR 평가셋

회의록 리스크 #2("OCR 인식 정확도 부족 — 약봉투 인쇄 품질 편차")에 대한 대응이다.
프롬프트를 감으로 고치지 않기 위해 숫자를 먼저 만든다.

**약봉투 원본 이미지는 커밋하지 않는다.** 개인 의료정보다.
`images/`는 `.gitignore`에 있고 각자 로컬에만 둔다. 공유가 필요하면 팀 공유 드라이브를 쓴다.

## 구성

```
evals/ocr/
├─ README.md
├─ cases.jsonl     # 정답셋 (이미지 파일명 + 기대 결과) — 커밋함
└─ images/         # 원본 이미지 — 커밋하지 않음
```

## `cases.jsonl` 형식

한 줄에 한 건.

```json
{"image": "case-001.jpg", "note": "일반 약국 인쇄, 상태 양호", "expected": [{"name": "아모잘탄정", "dose_frequency_per_day": 1}]}
{"image": "case-002.jpg", "note": "잉크 번짐", "expected": [{"name": "메트포르민서방정", "dose_frequency_per_day": 2}]}
```

`expected`에는 **약 이름과 1일 복용 횟수만** 적는다. 성분코드는 OCR이 읽을 수 있는
정보가 아니다.

## 목표

- 20건 수집 (다양한 인쇄 품질·약국·조명 조건)
- 지표: **약 이름 정확도**(가장 중요), 1일 횟수 정확도, 누락률, 환각률
- 환각(없는 약을 지어냄)은 누락보다 위험하다. 누락은 사용자가 직접 입력(OCR-07)으로
  메울 수 있지만 환각은 사용자가 알아채기 어렵다.

## 수집 시 주의

- 촬영자 본인 또는 동의를 받은 사람의 약봉투만 사용한다
- 환자명·주민번호·처방번호는 촬영 전에 가린다
- 파일명에 개인정보를 넣지 않는다 (`case-001.jpg` 형식)
