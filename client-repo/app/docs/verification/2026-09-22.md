브라우저 테스트는 실제 앱, 실제 Backend·PostgreSQL·AI·Anthropic SDK를 사용했고
외부 HTTP 응답만 합성했다. 사진은 작은 fixture PNG이며 실제 사진 인식 정확도의
검증이 아니다. 앱 코드에 테스트 성공용 우회 경로를 추가하지 않았다.
테스트 동안 화면에 표시되는 '가상', 'E2E' 약 이름과 숫자는 의학 정보가 아니다.

브라우저 스크립트: `tool/web_e2e.py`, 결과 화면:
[분석](insights.png), [보호자 리포트](caregiver-report.png).

알려진 도구 경고: Starlette 테스트의 anyio deprecation, 일부 음성 플러그인의 향후
Kotlin Gradle 마이그레이션 경고. 웹 기본 JS 빌드는 성공했으며 flutter_tts의 Wasm
사전 검사 경고가 있어 Wasm 빌드는 지원 확인 범위에 포함하지 않는다.


이 호스트에는 `/dev/kvm`이 없다. API 36 소프트웨어 에뮬레이터는 시스템 초기화가
완료되지 않아 APK 설치 시 `device is still booting`을 반환했다. Android 네이티브
E2E 성공으로 기록하지 않는다. `tool/android_reminder_smoke.py`는 준비했으나
부팅된 기기에서의 실제 실행은 남아 있다. 사용자용 `scripts/run_web.sh`는 별도로
직접 실행하여 Chromium에서 초기 화면이 열리는 것까지 확인했다.
